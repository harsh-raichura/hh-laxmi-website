# HH Laxmi E-commerce Platform

A modern e-commerce platform for **HH Laxmi** - Premium Farali & Millet Products.

## 🌾 Products We Offer

- **Rajgira Atta** - Premium amaranth flour for nutritious rotis
- **Moraiyo** - Barnyard millet for healthy meals  
- **Kodari** - Finger millet (Ragi) for strength
- **Sabudana** - Premium tapioca pearls for fasting
- **Methi Flour** - Fenugreek flour for health benefits
- **Seasonal Items** - Special products for festivals like Navratri

## 🚀 Technology Stack

- **Frontend**: Next.js 14, React 18, TypeScript
- **UI Components**: Material-UI (MUI)
- **Database**: Prisma with SQLite (development)
- **Styling**: CSS-in-JS with MUI themes
- **Authentication**: NextAuth.js
- **Payments**: Stripe integration
- **Image Gallery**: React Image Gallery
- **Forms**: React Hook Form
- **Notifications**: React Toastify

## 🛠 Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd hh-laxmi-ecommerce
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up the database:
   ```bash
   npm run db:push
   npm run db:generate
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.
